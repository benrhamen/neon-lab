# Neon Science Lab: Atoms, Alchemy & DNA

Neon pixel learning game. Mix real elements into real compounds (with alchemists' old names), brew potions for clients on a timer, and repair mutated DNA in the DNA clinic. A 118-element periodic table unlocks through quests, with a learning card for every element.

Self-contained single page, no external scripts or services. Scores and progress stay on the device (localStorage).

Fact cards link to their references: RSC Periodic Table, PubChem, NIST Chemistry WebBook, NHGRI Genome.gov, NobelPrize.org, Britannica, USGS, Science History Institute. Element data and element summaries come from Wikipedia through the open Periodic-Table-JSON dataset (CC BY-SA 3.0). Game reactions and ratios are simplified for play. Do not try chemistry at home.
